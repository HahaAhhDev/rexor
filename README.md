## Overview

Rexor is a multi-purpose toolkit that combines OSINT gathering, network reconnaissance, and stress testing into a single terminal application. The interface uses a straightforward JSON-style menu system with live-updating tables for attack statistics. Everything is color-coded in red because that's the aesthetic I settled on.

The project started as a collection of separate scripts that I eventually merged together to avoid switching between a dozen terminal windows. It's not production-grade software by any stretch, but it works for what it needs to do.

There's also a multi-vector mode that runs several methods simultaneously.

## Installation

### Requirements

- Python 3.9 or newer
- pip3
- Linux for full functionality (macOS and Windows work but with limitations)

### Quick Setup

```bash
# Clone the repository
git clone https://github.com/rexor/rexor.git
cd rexor

# Install Python dependencies
pip install -r requirements.txt

# Run it
python rexor.py
```

### Manual Dependency Installation

If the requirements file doesn't work for whatever reason, install these manually:

```bash
pip install rich colorama requests dnspython python-whois scapy urllib3
```

On Arch Linux, add `--break-system-packages` if pip refuses to install system-wide.

### Platform-Specific Notes

**Linux (recommended):**
```bash
sudo apt install python3 python3-pip network-manager
sudo python3 rexor.py  # for raw socket features
```

**macOS:**
WiFi scanning uses system_profiler. Raw socket operations still need sudo.
```bash
brew install python3
sudo python3 rexor.py
```

**Windows:**
Raw socket support is limited on Windows. Most attack methods that rely on ICMP or custom packet crafting won't function. Stick to TCP/UDP/HTTP methods and OSINT features.
```powershell
pip install -r requirements.txt
python rexor.py
```

## Usage

Launch the script and navigate with numbers:

```
REXOR > 1      # opens attack menu
REXOR > 2      # opens OSINT menu
REXOR > 3      # opens sniffer menu
REXOR > help   # shows available commands
REXOR > 0      # exit
```

### Example: Running a Username Search

```
REXOR > 2
OSINT > 1
Username: someusername
```

The tool will spin through all 75+ platforms with a progress bar, then display a table of results showing which platforms the username exists on.

### Example: Running an Attack

```
REXOR > 1
ATTACK > 10
Target IP: 192.168.1.100
Port: 80
Threads: 100
Sockets: 50
Packet Size: 1024
```

A live table appears showing packets sent, data transferred, errors, throughput, active socket count, proxy health, and top talkers. Press Ctrl+C to stop.

### Example: Domain Investigation

```
REXOR > 2
OSINT > 8
Domain: example.com
```

This runs WHOIS lookup, enumerates DNS records for all common types, brute-forces subdomains from a wordlist, queries certificate transparency logs, resolves the IP, and runs geolocation on it. Takes about 30-45 seconds depending on rate limits.
